# Field coverage and readable allowlist

Generated from the Prisma schema and executable privacy policy. All private scalars in the table use bound v2 ciphertext. Original typed columns contain keyed equality tokens or fixed null/empty/zero sentinels; they are not plaintext shadows. One-way authentication verifiers remain restricted material and are excluded from operator projections. `private_*`, `encryptedKey` and `legacyPrivateMetadata` are ciphertext, not readable content.

Operator DTOs use `operationalProjection`: only the above allowlist, further excluding object paths/buckets, nonce/key references, integrity/dedup hashes and storageUsageKey. Private ciphertext and credential verifiers are never projected. Admin package APIs expose only public seed definitions, and deletion/push endpoints return counts. Provisioning scripts are offline and never log identity values.
